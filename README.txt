РАСКРАСКА ВИКТОРИИ — интерактивный сайт

Откройте index.html в браузере. Для использования на iPad разместите папку на любом HTTPS-хостинге (например GitHub Pages или Netlify) и откройте адрес в Safari.

В комплекте 12 страниц из PDF, 16 цветов, 4 кисти, толщина, ластик, отмена/повтор, очистка, сохранение PNG, музыка.
Музыка оригинальная, создаётся в браузере и включается нажатием кнопки.
Рисунки на каждой странице сохраняются при переключении страниц в рамках открытой вкладки.
